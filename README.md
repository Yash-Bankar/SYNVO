# SYNVO

Synvo is a company-building partner for creators. We co-build software companies with creators: Synvo funds development and puts an operating team in place, while creators bring audience understanding and product direction. Equity, time, responsibilities, decision rights and financial commitments are agreed before development begins.

Help exceptional creators build and own enduring companies.

## This repository

The marketing site and research library for Synvo, built with Next.js and Tailwind CSS.

- `/` — single-page homepage with seven chapters (horizontal on desktop, vertical on mobile)
- `/research` — research index
- `/research/the-business-beyond-the-next-post` — flagship essay and its data figures

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build   # production build
npm run lint    # lint
```

## Stack

Next.js (App Router) · React · Tailwind CSS · Framer Motion · Manrope
